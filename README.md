## Engineering Standard

For projects actively being hardened, the repository includes an engineering review covering:

- Reproducible data paths and environment configuration
- Notebook hygiene and static validation
- Leakage-aware splitting and preprocessing
- Appropriate evaluation metrics and limitations
- Dependency declarations and repository hygiene
- Clear failure behavior when data or model artifacts are unavailable

Dataset-dependent metrics are never invented. A project is marked ready for publication only after its real dataset, environment, and end-to-end execution have been verified.
